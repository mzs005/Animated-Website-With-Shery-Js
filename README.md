Animated Website
This project is an animated website that showcases various animations and effects using libraries such as GSAP, Locomotive Scroll, and Shery.js. The website is designed to provide a smooth and visually appealing user experience with various sections including a hero section, motive section, image gallery, banner, and footer.

Project Structure
The project consists of the following files:

index.html: The main HTML file that contains the structure of the website.
style.css: The CSS file that contains the styles for the website.
script.js: The JavaScript file that contains the animations and effects for the website.
Libraries Used
GSAP: A powerful JavaScript library for creating animations.
Locomotive Scroll: A smooth scrolling library.
Shery.js: A library for creating text and image animations.
Features
Smooth Scrolling: Implemented using Locomotive Scroll for a smooth scrolling experience.
GSAP Animations: Various animations for elements such as navigation links, hero section, and images.
Shery.js Effects: Text and image animations using Shery.js for enhanced visual effects.
